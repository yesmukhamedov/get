# hello-get-lab

Simple Spring Boot (JDK 17) project demonstrating HTTP GET handling with one MVC endpoint and one REST endpoint.

## Run

```bash
mvn spring-boot:run
```

## Example URLs

- MVC: `http://localhost:8080/mvc/people/Amina?birthYear=2001`
- REST: `http://localhost:8080/api/people/Amina?birthYear=2001`
